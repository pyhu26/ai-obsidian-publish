📝 구현 과정

1. Realtime 구독 훅 생성

src/hooks/useRealtimeMarketData.ts

import { useEffect, useState } from 'react';
import { useQueryClient } from '@tanstack/react-query';
import { supabase } from '../lib/supabase';

export function useRealtimeMarketData() {
  const queryClient = useQueryClient();
  const [isConnected, setIsConnected] = useState(false);
  const [lastUpdate, setLastUpdate] = useState<Date | null>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    // Realtime 채널 생성
    const channel = supabase
      .channel('market-trends-changes')
      .on(
        'postgres_changes',
        {
          event: '*',  // INSERT, UPDATE, DELETE 모두 감지
          schema: 'public',
          table: 'market_trends',
        },
        (payload) => {
          console.log('데이터 변경 감지:', payload);

          // React Query 캐시 무효화 → 자동 재조회
          queryClient.invalidateQueries({ queryKey: ['marketData'] });

          setLastUpdate(new Date());
          setError(null);
        }
      )
      .subscribe((status) => {
        console.log('구독 상태:', status);

        if (status === 'SUBSCRIBED') {
          setIsConnected(true);
          setError(null);
        } else if (status === 'CLOSED') {
          setIsConnected(false);
          setError('연결이 종료되었습니다.');
        } else if (status === 'CHANNEL_ERROR') {
          setIsConnected(false);
          setError('채널 오류가 발생했습니다.');
        }
      });

    // 클린업: 컴포넌트 언마운트 시 구독 해제
    return () => {
      supabase.removeChannel(channel);
    };
  }, [queryClient]);

  return { isConnected, lastUpdate, error };
}

핵심 개념

  1. Channel: Supabase Realtime의 구독 단위
  2. postgres_changes: PostgreSQL 변경 이벤트 수신
  3. invalidateQueries: React Query 캐시 무효화 → 자동 재조회
  4. subscribe callback: 연결 상태 추적

2. Dashboard에서 사용

src/components/Dashboard.tsx

import { useRealtimeMarketData } from '../hooks/useRealtimeMarketData';

export function Dashboard() {
  const { data, isLoading, error } = useMarketData();
  const { isConnected, lastUpdate, error: realtimeError } = useRealtimeMarketData();

  return (
    <div>
      {/* 실시간 연결 상태 표시 */}
      <div className={`flex items-center gap-2 px-4 py-2 rounded-full ${
        isConnected
          ? 'bg-green-100 text-green-700'
          : 'bg-red-100 text-red-700'
      }`}>
        <span className={`w-2 h-2 rounded-full ${
          isConnected ? 'bg-green-500 animate-pulse' : 'bg-red-500'
        }`} />
        {isConnected ? '실시간 연결됨' : realtimeError || '연결 끊김'}
      </div>

      {lastUpdate && (
        <div className="text-sm text-gray-500">
          마지막 업데이트: {lastUpdate.toLocaleTimeString('ko-KR')}
        </div>
      )}

      {/* 차트들 */}
    </div>
  );
}

UI 특징

  • 녹색 점 + 애니메이션: 연결됨
  • 빨간색 점: 연결 끊김
  • 마지막 업데이트 시간: 실시간성 확인

3. React Query 캐시 무효화 전략

// 방법 1: 특정 쿼리만 무효화
queryClient.invalidateQueries({ queryKey: ['marketData'] });

// 방법 2: 모든 쿼리 무효화
queryClient.invalidateQueries();

// 방법 3: 직접 데이터 설정 (최적화)
queryClient.setQueryData(['marketData'], newData);

선택한 방법: invalidateQueries

  • 장점: React Query가 자동으로 재조회 (기존 로직 재사용)
  • 단점: 네트워크 요청 발생

대안: setQueryData

  • 장점: 네트워크 요청 없음 (payload에서 직접 업데이트)
  • 단점: 부분 업데이트만 가능 (전체 목록 재조회 필요 시 부적합)

🎯 결과

실시간 업데이트 동작 흐름

1. Supabase에서 데이터 변경 (INSERT/UPDATE/DELETE)
        ↓
2. Realtime 채널이 변경 이벤트 수신
        ↓
3. postgres_changes 콜백 실행
        ↓
4. React Query 캐시 무효화
        ↓
5. useMarketData 훅이 자동 재조회
        ↓
6. 차트 컴포넌트 자동 리렌더링

네트워크 흐름

[Supabase DB]
    │ (변경 발생)
    ▼
[Realtime Server]
    │ (WebSocket)
    ▼
[브라우저]
    ├─ useRealtimeMarketData (이벤트 수신)
    └─ React Query (데이터 재조회)

💡 배운 점

1. WebSocket의 가치

  • HTTP 폴링: 주기적으로 요청 → 비효율적, 실시간성 낮음
  • WebSocket: 양방향 연결 유지 → 효율적, 즉시 업데이트

2. React Query + Realtime 조합

// ❌ Realtime으로 받은 데이터를 직접 상태 관리
const [data, setData] = useState([]);
// → 복잡한 상태 동기화 필요

// ✅ React Query 캐시 무효화만 실행
queryClient.invalidateQueries(['marketData']);
// → React Query가 알아서 재조회

3. 연결 상태 관리의 중요성

  • 사용자가 네트워크 문제를 인지할 수 있도록
  • 디버깅 시 연결 상태 확인 가능
  • 재연결 로직 트리거

4. 클린업 함수

useEffect(() => {
  const channel = supabase.channel(...);

  return () => {
    // 컴포넌트 언마운트 시 구독 해제
    supabase.removeChannel(channel);
  };
}, []);

왜 필요한가?

  • 메모리 누수 방지
  • 불필요한 WebSocket 연결 유지 방지

🐛 트러블슈팅

문제 1: Realtime이 작동하지 않음

원인: Supabase 프로젝트에서 Realtime 활성화 안 됨

해결: Supabase Dashboard

  1. Database → Replication
  2. market_trends 테이블 Realtime 활성화
  3. Supabase 프로젝트 재시작

문제 2: 너무 자주 재조회됨

원인: 모든 행 변경마다 전체 데이터 재조회

해결: 필터 추가

.on('postgres_changes', {
  event: 'INSERT',  // INSERT만 감지
  schema: 'public',
  table: 'market_trends',
  filter: 'created_at=gte.2024-01-01'  // 최근 데이터만
}, ...)

문제 3: 연결이 자주 끊김

원인: 네트워크 불안정 or 서버 타임아웃

해결: 재연결 로직

useEffect(() => {
  const reconnect = () => {
    console.log('재연결 시도...');
    // 채널 재생성
  };

  if (!isConnected && error) {
    const timer = setTimeout(reconnect, 5000);
    return () => clearTimeout(timer);
  }
}, [isConnected, error]);
