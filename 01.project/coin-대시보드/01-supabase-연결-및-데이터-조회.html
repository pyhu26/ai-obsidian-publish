1. Supabase 클라이언트 설정

먼저 Supabase 클라이언트를 초기화하는 모듈을 작성했습니다.

src/lib/supabase.ts

import { createClient } from '@supabase/supabase-js';

const supabaseUrl = import.meta.env.VITE_SUPABASE_URL;
const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY;

if (!supabaseUrl || !supabaseAnonKey) {
  throw new Error('Supabase URL과 Anon Key가 필요합니다.');
}

export const supabase = createClient(supabaseUrl, supabaseAnonKey);

환경 변수 체크

  • Vite는 import.meta.env를 사용
  • VITE_ 접두사가 필요 (보안상 명시적으로 노출할 변수만 사용)
  • 초기화 시점에 필수 값 검증

2. TypeScript 타입 정의

데이터 구조를 명확히 하기 위해 타입을 정의했습니다.

src/types/index.ts

export interface MarketData {
  market_name: string;
  trend_weight: number;
  last_high_price: number;
  high_prices: number[] | null;
  timestamp_array: number[] | null;
  analysis_time: string | null;
  created_at: string;
}

export interface MarketStats {
  totalMarkets: number;
  averageTrend: number;
  positiveTrendCount: number;
}

설계 포인트

  • high_prices와 timestamp_array는 시계열 데이터용 (나중에 Line Chart에서 사용)
  • null 허용으로 유연성 확보
  • MarketStats는 통계 계산용 별도 타입

3. React Query 설정

src/lib/queryClient.ts

import { QueryClient } from '@tanstack/react-query';

export const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 1000 * 60 * 5, // 5분
      gcTime: 1000 * 60 * 10,   // 10분 (구 cacheTime)
      retry: 1,
      refetchOnWindowFocus: false,
    },
  },
});

캐싱 전략

  • staleTime: 5분 → 5분 동안은 캐시된 데이터 사용
  • gcTime: 10분 → 10분 후 가비지 컬렉션
  • retry: 1 → 실패 시 1번만 재시도 (빠른 실패)
  • refetchOnWindowFocus: false → 탭 전환 시 재조회 방지

4. 데이터 조회 훅 구현

src/hooks/useMarketData.ts

import { useQuery } from '@tanstack/react-query';
import { supabase } from '../lib/supabase';
import type { MarketData } from '../types';

export function useMarketData() {
  return useQuery({
    queryKey: ['marketData'],
    queryFn: async () => {
      const { data, error } = await supabase
        .from('market_trends')
        .select('*')
        .order('created_at', { ascending: false })
        .limit(1000);

      if (error) throw error;
      return data as MarketData[];
    },
  });
}

// 통계 계산 훅
export function useMarketStats(data: MarketData[] | undefined) {
  if (!data || data.length === 0) return null;

  return {
    totalMarkets: data.length,
    averageTrend: data.reduce((sum, d) => sum + d.trend_weight, 0) / data.length,
    positiveTrendCount: data.filter(d => d.trend_weight > 0.2).length,
  };
}

구현 특징

  • queryKey로 캐시 식별
  • Supabase의 .select('*') 문법 사용
  • 최신 데이터부터 정렬 (created_at desc)
  • 통계 계산은 별도 훅으로 분리 (재사용성)

5. App 컴포넌트에서 사용

src/App.tsx

import { QueryClientProvider } from '@tanstack/react-query';
import { queryClient } from './lib/queryClient';
import { Dashboard } from './components/Dashboard';

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <Dashboard />
    </QueryClientProvider>
  );
}

export default App;

214개의 마켓 데이터를 성공적으로 가져왔습니다!

캐싱 동작 확인

  1. 첫 로딩: Supabase에서 데이터 fetch (약 500ms)
  2. 5분 이내 재방문: 캐시된 데이터 즉시 표시 (0ms)
  3. 5분 경과 후: 백그라운드에서 자동 갱신

💡 배운 점

1. Vite 환경 변수 사용법

  • import.meta.env.VITE_* 형식으로만 접근 가능
  • .env 파일에 민감한 정보 저장
  • Git에 .env 파일은 커밋하지 않음 (.gitignore)

2. React Query의 강력함

  • 데이터 페칭, 캐싱, 에러 처리를 한 번에 해결
  • isLoading, error, data 상태를 자동 관리
  • 수동으로 useState, useEffect 쓸 필요 없음

3. TypeScript의 타입 안정성

// ❌ 컴파일 에러
const price: number = data.market_name;

// ✅ 타입 체크 통과
const price: number = data.last_high_price;

4. Supabase의 직관적인 API

// SQL: SELECT * FROM market_trends ORDER BY created_at DESC LIMIT 1000
const { data } = await supabase
  .from('market_trends')
  .select('*')
  .order('created_at', { ascending: false })
  .limit(1000);

🐛 트러블슈팅

문제 1: "Cannot find module '@supabase/supabase-js'"

원인: 패키지 설치 누락

해결:

npm install @supabase/supabase-js

문제 2: 환경 변수가 undefined

원인: VITE_ 접두사 누락

해결:

# ❌ 잘못된 형식
SUPABASE_URL=...

# ✅ 올바른 형식
VITE_SUPABASE_URL=...

문제 3: CORS 에러

원인: Supabase 프로젝트 설정에서 허용된 도메인 확인 필요

해결: Supabase Dashboard → Settings → API → Site URL 추가
