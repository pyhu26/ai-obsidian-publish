📝 구현 과정

1. Dashboard 컴포넌트 기본 구조

src/components/Dashboard.tsx

import { useMarketData, useMarketStats } from '../hooks/useMarketData';

export function Dashboard() {
  const { data, isLoading, error } = useMarketData();
  const stats = useMarketStats(data);

  if (isLoading) {
    return (
      <div className="flex items-center justify-center min-h-screen">
        <div className="text-lg text-gray-600">데이터 로딩 중...</div>
      </div>
    );
  }

  if (error) {
    return (
      <div className="flex items-center justify-center min-h-screen">
        <div className="text-lg text-red-600">
          오류가 발생했습니다: {error.message}
        </div>
      </div>
    );
  }

  return (
    <div className="min-h-screen bg-gray-50">
      {/* 헤더 및 통계 */}
      {/* 차트 영역 */}
    </div>
  );
}

구조 설계

  • 로딩 상태 → 중앙 정렬 로딩 메시지
  • 에러 상태 → 중앙 정렬 에러 메시지
  • 정상 상태 → 대시보드 전체 렌더링

2. 헤더 및 통계 카드

<header className="mb-8">
  <h1 className="text-4xl font-bold text-gray-900 mb-4">
    📊 코인 트렌드 대시보드
  </h1>

  {stats && (
    <div className="grid grid-cols-1 md:grid-cols-3 gap-4">
      <div className="bg-white rounded-lg shadow p-6">
        <div className="text-sm text-gray-500 mb-1">총 마켓 수</div>
        <div className="text-3xl font-bold text-gray-900">
          {stats.totalMarkets}
        </div>
      </div>

      <div className="bg-white rounded-lg shadow p-6">
        <div className="text-sm text-gray-500 mb-1">평균 트렌드</div>
        <div className="text-3xl font-bold text-blue-600">
          {stats.averageTrend.toFixed(3)}
        </div>
      </div>

      <div className="bg-white rounded-lg shadow p-6">
        <div className="text-sm text-gray-500 mb-1">상승세 마켓</div>
        <div className="text-3xl font-bold text-green-600">
          {stats.positiveTrendCount}
        </div>
      </div>
    </div>
  )}
</header>

스타일 특징

  • grid-cols-1 md:grid-cols-3: 모바일 1열, 데스크톱 3열
  • shadow: 카드 그림자 효과
  • rounded-lg: 둥근 모서리
  • 색상 구분: 기본(gray), 평균(blue), 상승(green)

3. 차트 영역 레이아웃

<div className="space-y-8">
  {/* Bar Chart */}
  <div className="bg-white rounded-lg shadow p-6">
    <h2 className="text-xl font-bold text-gray-900 mb-4">
      📈 트렌드 가중치 차트
    </h2>
    {/* 차트 컴포넌트가 들어갈 자리 */}
  </div>

  {/* Scatter Plot */}
  <div className="bg-white rounded-lg shadow p-6">
    <h2 className="text-xl font-bold text-gray-900 mb-4">
      📊 트렌드-가격 상관관계
    </h2>
    {/* 차트 컴포넌트가 들어갈 자리 */}
  </div>

  {/* Line Chart */}
  <div className="bg-white rounded-lg shadow p-6">
    <h2 className="text-xl font-bold text-gray-900 mb-4">
      📈 최고가 트렌드
    </h2>
    {/* 차트 컴포넌트가 들어갈 자리 */}
  </div>
</div>

레이아웃 전략

  • space-y-8: 세로 간격 자동 조절
  • 각 차트를 독립적인 카드로 분리
  • 차트 컴포넌트 교체가 용이한 구조

4. Container 및 Padding

<div className="min-h-screen bg-gray-50">
  <div className="container mx-auto px-4 py-8">
    {/* 모든 콘텐츠 */}
  </div>
</div>

컨테이너 설정

  • container mx-auto: 최대 너비 제한 + 중앙 정렬
  • px-4 py-8: 좌우 패딩 16px, 상하 패딩 32px
  • min-h-screen: 최소 높이를 화면 높이로 설정

🎨 Tailwind CSS 활용

반응형 브레이크포인트

// 모바일 (default)
grid-cols-1

// 태블릿 이상 (768px+)
md:grid-cols-3

유틸리티 클래스 조합

// 카드 스타일
bg-white rounded-lg shadow p-6

// 해석:
bg-white    // 배경색 흰색
rounded-lg  // 둥근 모서리 (8px)
shadow      // 그림자 효과
p-6         // 패딩 24px (모든 방향)

색상 시스템

text-gray-900   // 제목 (가장 진한 회색)
text-gray-500   // 부제목 (중간 회색)
text-blue-600   // 강조 (파란색)
text-green-600  // 긍정 (녹색)
text-red-600    // 에러 (빨간색)

💡 배운 점

1. Early Return 패턴

// ✅ 좋은 예: Early Return
if (isLoading) return <LoadingUI />;
if (error) return <ErrorUI />;
return <MainUI />;

// ❌ 나쁜 예: 중첩 조건문
return (
  <div>
    {isLoading ? <LoadingUI /> : (
      error ? <ErrorUI /> : <MainUI />
    )}
  </div>
);

2. Tailwind의 Mobile-First 접근

// 기본 = 모바일 스타일
grid-cols-1

// md: (768px 이상) = 태블릿/데스크톱 스타일
md:grid-cols-3

3. 시맨틱 HTML 구조

<header>  // 헤더 영역
<main>    // 메인 콘텐츠
<section> // 각 차트 섹션

4. 컴포넌트 분리 전략

  • 큰 컴포넌트 먼저 → 레이아웃 확정
  • 작은 컴포넌트 나중에 → 기능별 분리

🐛 트러블슈팅

문제 1: Tailwind 스타일이 적용 안 됨

원인: tailwind.config.js의 content 경로 설정 오류

해결:

// tailwind.config.js
content: [
  "./index.html",
  "./src/**/*.{js,ts,jsx,tsx}", // 모든 React 파일 포함
]

문제 2: 반응형이 동작하지 않음

원인: Viewport meta 태그 누락

해결: index.html에 추가

<meta name="viewport" content="width=device-width, initial-scale=1.0">

문제 3: 통계 값이 undefined

원인: 데이터 로딩 전에 stats 계산 시도

해결: 옵셔널 체이닝 사용

{stats && (
  <div>{stats.totalMarkets}</div>
)}
