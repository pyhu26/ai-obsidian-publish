💬 나의 요청

"데이터를 더 세밀하게 분석할 수 있도록 다양한 필터 기능을 만들어줘. 트렌드 가중치와 가격 범위를 슬라이더로 조절하고, 마켓명 검색도 되게 해줘. 정렬 옵션도 추가하고, 자주 사용하는 필터 조합은 프리셋으로 저장할 수 있게 해줘. 그리고 URL로 필터 상태를 공유할 수 있으면 좋겠어."

1. 필터 타입 정의

src/types/index.ts

export interface FilterOptions {
  trendRange: [number, number];      // [최소, 최대]
  priceRange: [number, number];      // [최소, 최대]
  searchText: string;                // 검색어
  sortBy: 'trend' | 'price' | 'name'; // 정렬 기준
  sortOrder: 'asc' | 'desc';         // 정렬 순서
}

export interface FilterPreset {
  id: string;
  name: string;
  filters: FilterOptions;
  createdAt: string;
}

타입 설계 특징

  • trendRange, priceRange: 튜플 타입으로 최소/최대값 표현
  • sortBy: 유니온 타입으로 허용 값 제한
  • FilterPreset: 저장된 필터 조합

2. useFilter 훅 - 필터링 로직

src/hooks/useFilter.ts

export function useFilter(data: MarketData[]) {
  const [filters, setFilters] = useState<FilterOptions>(DEFAULT_FILTERS);

  // 데이터의 최소/최대값 자동 계산
  const dataRange = useMemo(() => {
    if (!data || data.length === 0) {
      return { minTrend: 0, maxTrend: 1, minPrice: 0, maxPrice: 100000000 };
    }

    const trends = data.map((d) => d.trend_weight);
    const prices = data.map((d) => d.last_high_price);

    return {
      minTrend: Math.min(...trends),
      maxTrend: Math.max(...trends),
      minPrice: Math.min(...prices),
      maxPrice: Math.max(...prices),
    };
  }, [data]);

  // URL 쿼리 파라미터에서 필터 초기화
  useEffect(() => {
    const params = new URLSearchParams(window.location.search);

    const urlFilters: FilterOptions = {
      trendRange: [
        params.get('trendMin') ? parseFloat(params.get('trendMin')!) : dataRange.minTrend,
        params.get('trendMax') ? parseFloat(params.get('trendMax')!) : dataRange.maxTrend,
      ],
      priceRange: [
        params.get('priceMin') ? parseFloat(params.get('priceMin')!) : dataRange.minPrice,
        params.get('priceMax') ? parseFloat(params.get('priceMax')!) : dataRange.maxPrice,
      ],
      searchText: params.get('search') || '',
      sortBy: (params.get('sortBy') as FilterOptions['sortBy']) || 'trend',
      sortOrder: (params.get('sortOrder') as FilterOptions['sortOrder']) || 'desc',
    };

    setFilters(urlFilters);
  }, [dataRange]);

  // 필터 변경 시 URL 자동 업데이트
  useEffect(() => {
    const params = new URLSearchParams();

    // 기본값과 다를 때만 URL에 추가 (깔끔한 URL 유지)
    if (filters.trendRange[0] !== dataRange.minTrend) {
      params.set('trendMin', filters.trendRange[0].toString());
    }
    if (filters.trendRange[1] !== dataRange.maxTrend) {
      params.set('trendMax', filters.trendRange[1].toString());
    }
    // ... 나머지 필터들도 동일

    const newUrl = params.toString()
      ? `${window.location.pathname}?${params.toString()}`
      : window.location.pathname;

    window.history.replaceState({}, '', newUrl);
  }, [filters, dataRange]);

  // 필터링 및 정렬된 데이터
  const filteredData = useMemo(() => {
    if (!data) return [];

    let result = data.filter((item) => {
      // 트렌드 가중치 필터
      if (item.trend_weight < filters.trendRange[0] ||
          item.trend_weight > filters.trendRange[1]) {
        return false;
      }

      // 가격 범위 필터
      if (item.last_high_price < filters.priceRange[0] ||
          item.last_high_price > filters.priceRange[1]) {
        return false;
      }

      // 마켓명 검색
      if (filters.searchText) {
        const searchLower = filters.searchText.toLowerCase();
        if (!item.market_name.toLowerCase().includes(searchLower)) {
          return false;
        }
      }

      return true;
    });

    // 정렬
    result.sort((a, b) => {
      let compareValue = 0;

      switch (filters.sortBy) {
        case 'trend':
          compareValue = a.trend_weight - b.trend_weight;
          break;
        case 'price':
          compareValue = a.last_high_price - b.last_high_price;
          break;
        case 'name':
          compareValue = a.market_name.localeCompare(b.market_name);
          break;
      }

      return filters.sortOrder === 'asc' ? compareValue : -compareValue;
    });

    return result;
  }, [data, filters]);

  return { filters, setFilters, filteredData, resetFilters, dataRange };
}

핵심 구현

  1. 데이터 범위 자동 계산: 실제 데이터의 최소/최대값을 useMemo로 계산
  2. URL 동기화: 양방향 동기화 (URL → 필터, 필터 → URL)
  3. 필터링 로직: filter 메서드로 모든 조건 검증
  4. 정렬 로직: sort 메서드로 선택된 기준에 따라 정렬

3. useFilterPresets 훅 - 프리셋 관리

src/hooks/useFilterPresets.ts

const STORAGE_KEY = 'filter_presets';

export function useFilterPresets() {
  const [presets, setPresets] = useState<FilterPreset[]>([]);

  // 로컬스토리지에서 프리셋 불러오기
  useEffect(() => {
    const stored = localStorage.getItem(STORAGE_KEY);
    if (stored) {
      try {
        const parsed = JSON.parse(stored);
        setPresets(parsed);
      } catch (error) {
        console.error('프리셋 불러오기 오류:', error);
      }
    }
  }, []);

  // 프리셋 저장
  const savePreset = (name: string, filters: FilterOptions) => {
    const newPreset: FilterPreset = {
      id: Date.now().toString(),
      name,
      filters,
      createdAt: new Date().toISOString(),
    };

    const updatedPresets = [...presets, newPreset];
    setPresets(updatedPresets);
    localStorage.setItem(STORAGE_KEY, JSON.stringify(updatedPresets));
  };

  // 프리셋 삭제
  const deletePreset = (id: string) => {
    const updatedPresets = presets.filter((p) => p.id !== id);
    setPresets(updatedPresets);
    localStorage.setItem(STORAGE_KEY, JSON.stringify(updatedPresets));
  };

  // 프리셋 적용
  const loadPreset = (id: string): FilterOptions | null => {
    const preset = presets.find((p) => p.id === id);
    return preset ? preset.filters : null;
  };

  return { presets, savePreset, deletePreset, loadPreset };
}

LocalStorage 패턴

  • 컴포넌트 마운트 시 자동 로드
  • 상태 변경 시 즉시 LocalStorage에 저장
  • 브라우저 재시작 후에도 프리셋 유지

4. FilterPanel 컴포넌트

src/components/FilterPanel.tsx

export function FilterPanel({
  filters,
  onFiltersChange,
  onReset,
  minTrend,
  maxTrend,
  minPrice,
  maxPrice,
  onSavePreset,
  onLoadPreset,
}: FilterPanelProps) {
  const handleTrendRangeChange = (index: 0 | 1, value: number) => {
    const newRange: [number, number] = [...filters.trendRange];
    newRange[index] = value;
    onFiltersChange({ ...filters, trendRange: newRange });
  };

  return (
    <div className="bg-white rounded-lg shadow p-6 mb-6">
      <div className="flex items-center justify-between mb-6">
        <h2 className="text-xl font-bold text-gray-900">🔍 필터 옵션</h2>
        <div className="flex gap-2">
          <button onClick={onLoadPreset}>불러오기</button>
          <button onClick={onSavePreset}>저장</button>
          <button onClick={onReset}>초기화</button>
        </div>
      </div>

      {/* 마켓명 검색 */}
      <div>
        <label>마켓명 검색</label>
        <input
          type="text"
          value={filters.searchText}
          onChange={(e) => onFiltersChange({
            ...filters,
            searchText: e.target.value
          })}
          placeholder="KRW-BTC, KRW-ETH..."
        />
      </div>

      {/* 트렌드 가중치 범위 (듀얼 슬라이더) */}
      <div>
        <label>
          트렌드 가중치: {filters.trendRange[0].toFixed(3)} ~
          {filters.trendRange[1].toFixed(3)}
        </label>
        <div className="space-y-2">
          {/* 최소값 슬라이더 */}
          <input
            type="range"
            min={minTrend}
            max={maxTrend}
            step={(maxTrend - minTrend) / 1000}
            value={filters.trendRange[0]}
            onChange={(e) => handleTrendRangeChange(0, parseFloat(e.target.value))}
          />
          {/* 최대값 슬라이더 */}
          <input
            type="range"
            min={minTrend}
            max={maxTrend}
            step={(maxTrend - minTrend) / 1000}
            value={filters.trendRange[1]}
            onChange={(e) => handleTrendRangeChange(1, parseFloat(e.target.value))}
          />
        </div>
      </div>

      {/* 가격 범위 (동일 패턴) */}

      {/* 정렬 옵션 */}
      <div>
        <label>정렬 기준</label>
        <div className="flex gap-2">
          <button
            onClick={() => onFiltersChange({ ...filters, sortBy: 'trend' })}
            className={filters.sortBy === 'trend' ? 'active' : ''}
          >
            트렌드 {filters.sortBy === 'trend' && (filters.sortOrder === 'asc' ? '↑' : '↓')}
          </button>
          <button
            onClick={() => onFiltersChange({ ...filters, sortBy: 'price' })}
            className={filters.sortBy === 'price' ? 'active' : ''}
          >
            가격 {filters.sortBy === 'price' && (filters.sortOrder === 'asc' ? '↑' : '↓')}
          </button>
          <button
            onClick={() => onFiltersChange({ ...filters, sortBy: 'name' })}
            className={filters.sortBy === 'name' ? 'active' : ''}
          >
            이름 {filters.sortBy === 'name' && (filters.sortOrder === 'asc' ? '↑' : '↓')}
          </button>
          {/* 정렬 순서 토글 버튼 */}
          <button
            onClick={() => onFiltersChange({
              ...filters,
              sortOrder: filters.sortOrder === 'asc' ? 'desc' : 'asc'
            })}
          >
            {filters.sortOrder === 'asc' ? '↑' : '↓'}
          </button>
        </div>
      </div>
    </div>
  );
}

UI 특징

  • 듀얼 슬라이더: 최소/최대값을 두 개의 슬라이더로 조절
  • 실시간 값 표시: 라벨에 현재 선택된 범위 표시
  • 조건부 스타일: 선택된 정렬 기준은 active 클래스
  • 정렬 순서 표시: ↑(오름차순), ↓(내림차순) 아이콘

5. PresetModal 컴포넌트

src/components/PresetModal.tsx

export function PresetModal({
  isOpen,
  onClose,
  presets,
  onLoad,
  onSave,
  onDelete,
}: PresetModalProps) {
  const [presetName, setPresetName] = useState('');
  const [isSaveMode, setIsSaveMode] = useState(false);

  const handleSave = () => {
    if (presetName.trim()) {
      onSave(presetName);
      setPresetName('');
      setIsSaveMode(false);
    }
  };

  if (!isOpen) return null;

  return (
    <div className="fixed inset-0 bg-black bg-opacity-50 flex items-center justify-center z-50">
      <div className="bg-white rounded-lg p-6 max-w-md w-full mx-4">
        <h3 className="text-xl font-bold mb-4">필터 프리셋 관리</h3>

        {/* 저장 모드 */}
        {isSaveMode ? (
          <div className="mb-4">
            <input
              type="text"
              value={presetName}
              onChange={(e) => setPresetName(e.target.value)}
              placeholder="프리셋 이름"
              className="w-full px-4 py-2 border rounded mb-2"
            />
            <div className="flex gap-2">
              <button onClick={handleSave}>저장</button>
              <button onClick={() => setIsSaveMode(false)}>취소</button>
            </div>
          </div>
        ) : (
          <button onClick={() => setIsSaveMode(true)}>새 프리셋 저장</button>
        )}

        {/* 프리셋 목록 */}
        <div className="space-y-2 mt-4">
          {presets.map((preset) => (
            <div key={preset.id} className="flex items-center justify-between p-3 bg-gray-50 rounded">
              <div>
                <div className="font-medium">{preset.name}</div>
                <div className="text-sm text-gray-500">
                  {new Date(preset.createdAt).toLocaleDateString('ko-KR')}
                </div>
              </div>
              <div className="flex gap-2">
                <button
                  onClick={() => {
                    onLoad(preset.id);
                    onClose();
                  }}
                >
                  불러오기
                </button>
                <button onClick={() => onDelete(preset.id)}>삭제</button>
              </div>
            </div>
          ))}
          {presets.length === 0 && (
            <p className="text-gray-500 text-center py-4">
              저장된 프리셋이 없습니다.
            </p>
          )}
        </div>

        <button onClick={onClose} className="mt-4 w-full">닫기</button>
      </div>
    </div>
  );
}

6. Dashboard에서 통합

src/components/Dashboard.tsx

export function Dashboard() {
  const { data } = useMarketData();
  const { filters, setFilters, filteredData, resetFilters, dataRange } = useFilter(data);
  const { presets, savePreset, deletePreset, loadPreset } = useFilterPresets();
  const [isPresetModalOpen, setIsPresetModalOpen] = useState(false);

  const handleSavePreset = (name: string) => {
    savePreset(name, filters);
  };

  const handleLoadPreset = (id: string) => {
    const presetFilters = loadPreset(id);
    if (presetFilters) {
      setFilters(presetFilters);
    }
  };

  return (
    <div>
      {/* 필터 패널 */}
      <FilterPanel
        filters={filters}
        onFiltersChange={setFilters}
        onReset={resetFilters}
        minTrend={dataRange.minTrend}
        maxTrend={dataRange.maxTrend}
        minPrice={dataRange.minPrice}
        maxPrice={dataRange.maxPrice}
        onSavePreset={() => setIsPresetModalOpen(true)}
        onLoadPreset={() => setIsPresetModalOpen(true)}
      />

      {/* 프리셋 모달 */}
      <PresetModal
        isOpen={isPresetModalOpen}
        onClose={() => setIsPresetModalOpen(false)}
        presets={presets}
        onSave={handleSavePreset}
        onLoad={handleLoadPreset}
        onDelete={deletePreset}
      />

      {/* 필터링된 데이터를 차트에 전달 */}
      <TrendBarChart data={filteredData} />
      <TrendScatterPlot data={filteredData} />
      <PriceLineChart data={filteredData} />
    </div>
  );
}

문제 1: URL 파라미터 파싱 오류

원인: 숫자를 문자열로 읽어서 비교 실패

해결: parseFloat로 숫자 변환

const trendMin = params.get('trendMin');
const value = trendMin ? parseFloat(trendMin) : defaultMin;

문제 2: 슬라이더가 역전됨

원인: 최소값 슬라이더를 최대값보다 크게 설정 가능

해결: 슬라이더 값 검증

const handleTrendRangeChange = (index: 0 | 1, value: number) => {
  const newRange: [number, number] = [...filters.trendRange];
  newRange[index] = value;

  // 최소값이 최대값보다 크면 조정
  if (newRange[0] > newRange[1]) {
    newRange[1] = newRange[0];
  }

  onFiltersChange({ ...filters, trendRange: newRange });
};

문제 3: 프리셋 삭제 후 화면 미갱신

원인: LocalStorage는 업데이트했지만 상태 미변경

해결: 상태와 LocalStorage 동시 업데이트

const deletePreset = (id: string) => {
  const updatedPresets = presets.filter((p) => p.id !== id);
  setPresets(updatedPresets);  // 상태 업데이트
  localStorage.setItem(STORAGE_KEY, JSON.stringify(updatedPresets));  // 저장
};

문제 4: URL이 너무 길어짐

원인: 모든 필터 값을 URL에 포함

해결: 기본값과 다를 때만 URL에 추가

// 기본값과 다를 때만 파라미터 추가
if (filters.trendRange[0] !== dataRange.minTrend) {
  params.set('trendMin', filters.trendRange[0].toString());
}
