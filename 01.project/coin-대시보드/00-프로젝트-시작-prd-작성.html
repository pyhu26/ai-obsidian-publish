00-프로젝트-시작-PRD-작성

바이브 코딩기 - 코인 대시보드 만들기 (0) 프로젝트 시작과 PRD 작성

💬 나의 요청

"Supabase에 저장된 암호화폐 시장 데이터를 시각화하는 대시보드를 만들고 싶어. 데이터는 ./markets.csv 파일을 참고해주고 트렌드 가중치와 가격 데이터를 차트로 보여주고, 추세선도 표시하고 싶어 기술 스택은 react, vite로 만들었으면 좋겠고 대략적인 ui 디자인을 ascii 코드로 포함이 되었으면 좋겠어"

🤖 Claude의 작업 : PRD (Product Requirements Document) 작성

프로젝트를 시작하기 전, 먼저 요구사항을 명확히 정리하는 PRD 문서를 작성했습니다.

프로젝트 개요

  • 목적: Supabase에 저장된 암호화폐 시장 데이터를 실시간으로 가져와 시각화
  • 형태: 1페이지 React 웹 대시보드
  • 핵심 가치: 트렌드 분석과 가격 추이를 직관적으로 파악

데이터 구조

interface MarketData {
  market_name: string;      // 마켓명 (예: KRW-BTC)
  trend_weight: number;     // 트렌드 가중치 (0~1)
  last_high_price: number;  // 최근 최고가
  analysis_time: string;    // 분석 시간
}

주요 기능 정의

1. 전체 마켓 개요

  • 총 마켓 수
  • 평균 트렌드 가중치
  • 상승세 마켓 수 (trend_weight > 0.2)

2. 차트 3종 세트

  1. Bar Chart: 트렌드 가중치 상위 마켓 + 추세선
  2. Scatter Plot: 트렌드 가중치 vs 가격 상관관계 + 추세선
  3. Line Chart: 시간별 가격 추이 + 추세선

기술 스택 선정

Frontend
├── React (Vite)
├── TypeScript
├── Tailwind CSS
├── Recharts (차트 라이브러리)
└── React Query (데이터 캐싱)

Backend
└── Supabase (실시간 데이터베이스)

왜 이 스택인가?

  • Vite: 빠른 개발 서버와 빌드 속도
  • Recharts: 추세선 구현이 용이하고 커스터마이징이 자유로움
  • React Query: 자동 캐싱과 리페칭으로 실시간 업데이트 구현에 유리
  • Supabase: PostgreSQL 기반으로 실시간 구독 기능 제공

개발 우선순위 (Phase 구분)

Phase 1 (MVP - 핵심 기능)

  1. Supabase 연결 및 데이터 조회
  2. 기본 대시보드 레이아웃
  3. 트렌드 가중치 Bar Chart + 추세선
  4. 트렌드-가격 Scatter Plot + 추세선

Phase 2 (고도화)

  1. 실시간 데이터 업데이트
  2. 시간별 가격 추이 Line Chart
  3. 고급 필터링 기능
  4. 반응형 디자인

🤖 Claude의 작업 : GitHub 이슈 생성

PRD를 기반으로 Phase 1 작업을 GitHub Issues로 분리했습니다.

이슈 생성 과정

# 로컬에서 PRD.md 작성 후 커밋
git add PRD.md
git commit -m "docs: PRD 문서 추가"
git push

# GitHub Issues 생성
gh issue create --title "[Phase 1] Supabase 연결 및 데이터 조회 구현" \
  --body "$(cat <<EOF
## 목표
Supabase 클라이언트를 설정하고 암호화폐 시장 데이터를 조회하는 기능 구현

## 작업 내용
- [ ] Supabase 프로젝트 설정 및 API 키 획득
- [ ] Supabase 클라이언트 라이브러리 설치
- [ ] 환경 변수 설정 (.env)
- [ ] 데이터 조회 API 함수 작성
- [ ] React Query를 사용한 데이터 캐싱 구현

## 완료 조건
- Supabase에서 데이터를 성공적으로 조회할 수 있음
- 데이터가 적절히 캐싱됨
- 에러 핸들링이 구현됨
EOF
)"

gh issue create --title "[Phase 1] 기본 대시보드 레이아웃 구현"
gh issue create --title "[Phase 1] 마켓별 트렌드 가중치 차트 + 추세선 구현"
gh issue create --title "[Phase 1] 트렌드-가격 상관관계 Scatter Plot + 추세선 구현"

🤖 Cluade의 작업 : 프로젝트 초기 설정

1. Vite 프로젝트 생성

npm create vite@latest coin-dashboard -- --template react-ts
cd coin-dashboard
npm install

2. 필수 패키지 설치

# UI & 스타일링
npm install tailwindcss postcss autoprefixer
npx tailwindcss init -p

# 차트 라이브러리
npm install recharts

# 상태 관리 & 데이터 페칭
npm install @tanstack/react-query

# Supabase 클라이언트
npm install @supabase/supabase-js

3. 환경 변수 설정

.env 파일 생성:

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

4. Tailwind CSS 설정

tailwind.config.js:

/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}

5. 프로젝트 구조

coin-dashboard/
├── src/
│   ├── components/       # React 컴포넌트
│   ├── hooks/           # 커스텀 훅
│   ├── lib/             # 라이브러리 설정
│   ├── types/           # TypeScript 타입 정의
│   └── utils/           # 유틸리티 함수
├── PRD.md               # 프로젝트 요구사항 문서
└── README.md

6. 초기 커밋

git add .
git commit -m "feat: 프로젝트 초기 설정 완료"
git push

💡 배운 점

1. PRD 작성의 중요성

  • 코딩을 시작하기 전에 요구사항을 명확히 하니 개발 방향이 뚜렷해짐
  • 우선순위를 미리 정해두니 MVP에 집중할 수 있었음

2. Phase 구분의 효과

  • Phase 1 (MVP)과 Phase 2 (고도화)로 나누니 완성도 있는 단계별 개발 가능
  • 각 Phase별로 배포하여 빠른 피드백 수집 가능

3. GitHub Issues를 활용한 작업 관리

  • 각 작업을 이슈로 분리하니 진행 상황 추적이 명확
  • 커밋 메시지에 이슈 번호를 연결하면 자동으로 연관관계 생성
