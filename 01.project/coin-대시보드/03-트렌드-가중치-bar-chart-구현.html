1. 선형 회귀 유틸리티 함수

추세선을 그리기 위해 먼저 선형 회귀 계산 로직을 구현했습니다.

src/utils/linearRegression.ts

export function calculateLinearRegression(data: { x: number; y: number }[]) {
  const n = data.length;
  const sumX = data.reduce((sum, p) => sum + p.x, 0);
  const sumY = data.reduce((sum, p) => sum + p.y, 0);
  const sumXY = data.reduce((sum, p) => sum + p.x * p.y, 0);
  const sumXX = data.reduce((sum, p) => sum + p.x * p.x, 0);

  // y = mx + b 계산
  const slope = (n * sumXY - sumX * sumY) / (n * sumXX - sumX * sumX);
  const intercept = (sumY - slope * sumX) / n;

  return { slope, intercept };
}

export function getTrendLinePoints(
  data: { x: number; y: number }[],
  slope: number,
  intercept: number
) {
  return data.map(({ x }) => ({
    x,
    y: slope * x + intercept,
  }));
}

수학 공식

기울기(slope) = (n·Σxy - Σx·Σy) / (n·Σx² - (Σx)²)
절편(intercept) = (Σy - slope·Σx) / n
추세선 y값 = slope·x + intercept

2. TrendBarChart 컴포넌트

src/components/TrendBarChart.tsx

import { useState, useMemo } from 'react';
import {
  BarChart, Bar, XAxis, YAxis, CartesianGrid,
  Tooltip, Legend, ResponsiveContainer, Line,
} from 'recharts';
import { calculateLinearRegression, getTrendLinePoints } from '../utils/linearRegression';
import type { MarketData } from '../types';

interface TrendBarChartProps {
  data: MarketData[];
}

export function TrendBarChart({ data }: TrendBarChartProps) {
  const [displayCount, setDisplayCount] = useState(20);

  const chartData = useMemo(() => {
    // 트렌드 가중치 기준 내림차순 정렬 후 상위 N개 선택
    const sortedData = [...data]
      .sort((a, b) => b.trend_weight - a.trend_weight)
      .slice(0, displayCount);

    // 선형 회귀 계산
    const regressionData = sortedData.map((item, index) => ({
      x: index,
      y: item.trend_weight,
    }));

    const { slope, intercept } = calculateLinearRegression(regressionData);
    const trendLine = getTrendLinePoints(regressionData, slope, intercept);

    // 차트 데이터 변환
    return sortedData.map((item, index) => ({
      market_name: item.market_name,
      trend_weight: item.trend_weight,
      trendLine: trendLine[index].y,
    }));
  }, [data, displayCount]);

  const displayOptions = [10, 20, 30, 50, 100];

  return (
    <div className="space-y-4">
      {/* 표시 개수 선택 */}
      <div className="flex items-center justify-between">
        <h3 className="text-lg font-semibold text-gray-700">
          상위 {displayCount}개 마켓
        </h3>
        <select
          value={displayCount}
          onChange={(e) => setDisplayCount(Number(e.target.value))}
          className="px-3 py-2 border border-gray-300 rounded-md"
        >
          {displayOptions.map((option) => (
            <option key={option} value={option}>
              {option}개
            </option>
          ))}
        </select>
      </div>

      {/* 차트 */}
      <ResponsiveContainer width="100%" height={400}>
        <BarChart
          data={chartData}
          margin={{ top: 20, right: 30, left: 20, bottom: 60 }}
        >
          <CartesianGrid strokeDasharray="3 3" stroke="#e0e0e0" />
          <XAxis
            dataKey="market_name"
            angle={-45}
            textAnchor="end"
            height={100}
            tick={{ fontSize: 12 }}
          />
          <YAxis
            label={{ value: '트렌드 가중치', angle: -90, position: 'insideLeft' }}
          />
          <Tooltip
            contentStyle={{
              backgroundColor: 'white',
              border: '1px solid #ccc',
              borderRadius: '4px',
            }}
            formatter={(value: number) => [value.toFixed(6), '트렌드 가중치']}
          />
          <Legend />
          <Bar
            dataKey="trend_weight"
            fill="#3b82f6"
            radius={[4, 4, 0, 0]}
          />
          <Line
            type="monotone"
            dataKey="trendLine"
            stroke="#ef4444"
            strokeWidth={2}
            strokeDasharray="5 5"
            dot={false}
            name="추세선"
          />
        </BarChart>
      </ResponsiveContainer>

      {/* 통계 정보 */}
      <div className="text-sm text-gray-600 text-center">
        표시된 마켓: {chartData.length}개 / 전체: {data.length}개
      </div>
    </div>
  );
}

핵심 구현 포인트

  1. useMemo: displayCount나 data 변경 시에만 재계산
  2. 정렬: sort((a, b) => b.trend_weight - a.trend_weight) - 내림차순
  3. 추세선: Line 컴포넌트로 trendLine 데이터 오버레이
  4. 반응형: ResponsiveContainer로 자동 크기 조정

3. Recharts 스타일링

// X축 라벨 45도 회전
<XAxis
  dataKey="market_name"
  angle={-45}        // 반시계 방향 45도
  textAnchor="end"   // 끝점 기준 정렬
  height={100}       // 충분한 높이 확보
/>

// 바 차트 둥근 모서리
<Bar
  dataKey="trend_weight"
  fill="#3b82f6"           // 파란색
  radius={[4, 4, 0, 0]}    // 상단만 둥글게
/>

// 추세선 점선 스타일
<Line
  stroke="#ef4444"         // 빨간색
  strokeWidth={2}
  strokeDasharray="5 5"    // 5px 선, 5px 공백
  dot={false}              // 데이터 포인트 숨김
/>

추세선 해석

  • 기울기가 음수: 트렌드 가중치가 순위에 따라 감소 (정상적)
  • 기울기의 크기: 상위 마켓과 하위 마켓의 격차
  • 회귀선: 전반적인 경향성 파악

💡 배운 점

1. Recharts의 강력함

  • 선언적 API로 복잡한 차트를 간단히 구현
  • ResponsiveContainer로 반응형 자동 처리
  • 여러 차트 타입을 한 공간에 오버레이 가능 (Bar + Line)

2. useMemo의 활용

// ❌ 매 렌더링마다 재계산 (비효율)
const chartData = sortAndCalculate(data, displayCount);

// ✅ 의존성 변경 시에만 재계산
const chartData = useMemo(() =>
  sortAndCalculate(data, displayCount),
  [data, displayCount]
);

3. 선형 회귀의 가치

  • 복잡한 데이터에서 단순한 경향성 추출
  • 이상치(outlier) 파악 가능
  • 미래 예측의 기초

4. 데이터 변환 패턴

// 원본 데이터 → 정렬 → 필터링 → 계산 → 차트 데이터
data
  .sort(...)          // 1. 정렬
  .slice(0, N)        // 2. 상위 N개
  .map(...)           // 3. 형식 변환

문제 1: X축 라벨이 겹침

원인: 마켓명이 길어서 서로 겹침

해결: 45도 회전 + 충분한 높이

<XAxis
  angle={-45}
  textAnchor="end"
  height={100}  // 기본 30px → 100px
/>

문제 2: 추세선이 바 뒤에 가려짐

원인: SVG 렌더링 순서 (먼저 그린 것이 뒤에)

해결: Bar보다 Line을 나중에 선언

<Bar ... />    {/* 먼저 */}
<Line ... />   {/* 나중에 (위에 그려짐) */}

문제 3: 차트가 화면을 벗어남

원인: 고정 너비 사용

해결: ResponsiveContainer 사용

<ResponsiveContainer width="100%" height={400}>
  <BarChart>...</BarChart>
</ResponsiveContainer>
