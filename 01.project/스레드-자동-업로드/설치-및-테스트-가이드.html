🚀 n8n 스레드 자동 업로드 MVP - 설치 및 테스트 가이드

📋 사전 준비사항

시스템 요구사항

  • Node.js: 18.0.0 이상
  • npm: 8.0.0 이상
  • 메모리: 최소 2GB RAM
  • 운영체제: Windows, macOS, Linux

필수 계정 및 API 키

  • ✅ OpenAI API 키
  • ✅ Meta/Instagram 비즈니스 계정 (Threads API용)
  • ⚠️ 슬랙 웹훅 URL (권장)

🛠️ 1. n8n 설치 및 실행

방법 1: npm으로 글로벌 설치 (권장)

# n8n 전역 설치
npm install n8n -g

# n8n 실행
n8n start

# 브라우저에서 접속
# http://localhost:5678

방법 2: npx로 임시 실행

# 설치 없이 바로 실행
npx n8n

# 브라우저에서 접속
# http://localhost:5678

방법 3: Docker 사용

# n8n Docker 컨테이너 실행
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

# 백그라운드 실행
docker run -d \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  --restart unless-stopped \
  n8nio/n8n

⚙️ 2. 초기 설정

1단계: 첫 로그인 및 계정 생성

  1. 브라우저에서 http://localhost:5678 접속
  2. 첫 방문 시 계정 생성 화면
  3. 이메일 주소와 비밀번호 설정
  4. "Get started" 클릭

2단계: 기본 설정 확인

  1. 좌측 메뉴에서 "Settings" 클릭
  2. "General" 탭에서 시간대 설정: Asia/Seoul
  3. "Security" 탭에서 인증 설정 (선택사항)

🔑 3. 크리덴셜 설정

OpenAI API 크리덴셜 추가

  1. 좌측 메뉴에서 "Credentials" 클릭
  2. "Add Credential" 버튼 클릭
  3. "OpenAI" 검색하여 선택
  4. 다음 정보 입력: 
    Name: OpenAI API
API Key: sk-proj-your-openai-api-key-here
  5. "Save" 클릭

Threads API 크리덴셜 추가

  1. "Add Credential" 버튼 클릭
  2. "HTTP Header Auth" 선택
  3. 다음 정보 입력: 
    Name: Threads API
Header Name: Authorization
Header Value: Bearer YOUR_THREADS_ACCESS_TOKEN
  4. "Save" 클릭

환경변수 설정 (슬랙 웹훅)

n8n 실행 전에 환경변수를 설정합니다:

# Linux/macOS
export SLACK_WEBHOOK_URL="https://hooks.slack.com/services/T00/B00/XXX"

# Windows
set SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T00/B00/XXX

# 또는 .env 파일 생성
echo "SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T00/B00/XXX" > .env

📥 4. 워크플로우 가져오기

1단계: 워크플로우 JSON 파일 준비

  • 제공된 threads-mvp-workflow.json 파일을 다운로드

2단계: n8n에서 워크플로우 가져오기

  1. n8n 웹 인터페이스에서 "Import" 버튼 클릭
  2. "From File" 탭 선택
  3. threads-mvp-workflow.json 파일 업로드
  4. "Import" 클릭

3단계: 크리덴셜 연결

가져온 워크플로우의 각 노드에 크리덴셜을 연결:

  1. OpenAI 콘텐츠 생성 노드 클릭
  2. "Credential to connect with" 드롭다운에서 "OpenAI API" 선택
  3. 스레드 게시 노드 클릭
  4. "Credential to connect with" 드롭다운에서 "Threads API" 선택

4단계: 워크플로우 저장

  1. 우측 상단 "Save" 버튼 클릭
  2. 워크플로우 이름 확인: "스레드 자동 업로드 MVP"

🧪 5. 단계별 테스트

테스트 1: OpenAI API 연결 확인

  1. OpenAI 콘텐츠 생성 노드만 선택
  2. "Execute Node" 버튼 클릭
  3. 예상 결과: 한국어로 된 코딩 팁 콘텐츠 생성

✅ 성공 예시:

{
  "choices": [
    {
      "message": {
        "content": "VS Code에서 Ctrl+P로 파일을 빠르게 찾을 수 있지만, Ctrl+Shift+P로 명령 팔레트를 열면 더 많은 기능을 활용할 수 있어요. 'format document'로 코드 정리, 'toggle terminal'로 터미널 열기 등 모든 작업이 키보드로 가능합니다. 마우스 없이도 개발 속도가 2배 빨라져요! #VSCode #개발팁 #생산성"
      }
    }
  ]
}

❌ 실패 시 확인사항:

  • OpenAI API 키가 올바른지 확인
  • API 키에 충분한 크레딧이 있는지 확인
  • 인터넷 연결 상태 확인

테스트 2: 콘텐츠 검증 로직 확인

  1. 콘텐츠 검증 노드 선택
  2. "Execute Node" 버튼 클릭
  3. 예상 결과: 콘텐츠 품질 검증 결과

✅ 성공 예시:

{
  "content": "VS Code에서 Ctrl+P로 파일을 빠르게...",
  "length": 145,
  "hashtags": 3,
  "timestamp": "2024-09-23T09:00:00.000Z"
}

테스트 3: 슬랙 알림 확인

  1. 슬랙 성공 알림 노드 선택
  2. "Execute Node" 버튼 클릭
  3. 슬랙 채널에서 알림 메시지 확인

✅ 성공 시: 슬랙 채널에 게시 성공 메시지 수신

테스트 4: 전체 워크플로우 수동 실행

  1. 좌측 "Execute Workflow" 버튼 클릭
  2. 모든 노드가 순차적으로 실행되는지 확인
  3. 각 단계의 결과 데이터 검토

🕐 6. 자동 실행 설정 및 테스트

크론 트리거 활성화

  1. 매일 오전 9시 트리거 노드 클릭
  2. "Settings" 탭에서 "Always Output Data" 체크
  3. 워크플로우 상단의 "Activate" 토글을 ON으로 설정

테스트용 임시 스케줄 설정

실제 테스트를 위해 1분 후 실행되도록 임시 설정:

  1. 크론 노드의 "Rule" 수정
  2. 현재 시간 + 1분으로 설정 
    예시: 현재 14:30이면 "31 14 * * *" 입력
  3. 워크플로우 저장 및 활성화
  4. 1분 후 자동 실행 확인

실행 이력 확인

  1. 좌측 메뉴에서 "Executions" 클릭
  2. 최근 실행 결과 확인
  3. 성공/실패 상태 및 상세 로그 검토

⚠️ 7. 문제해결 가이드

자주 발생하는 오류들

1. OpenAI API 오류

Error: Request failed with status code 401

해결방법:

  • API 키 재확인 (sk-proj-로 시작하는지)
  • OpenAI 계정의 결제 상태 확인
  • API 사용량 제한 확인

2. Threads API 오류

Error: Invalid OAuth access token

해결방법:

  • Instagram 계정이 비즈니스 계정인지 확인
  • Meta Business Suite에서 앱 승인 상태 확인
  • 액세스 토큰 재발급

3. 콘텐츠 검증 실패

Error: 콘텐츠가 비어있거나 너무 깁니다

해결방법:

  • OpenAI 프롬프트 조정
  • 응답 길이 제한 확인 (maxTokens: 150)
  • temperature 값 조정 (0.7 권장)

4. 슬랙 알림 실패

Error: channel_not_found

해결방법:

  • 웹훅 URL 재확인
  • 슬랙 채널 존재 여부 확인
  • 봇 권한 설정 확인

디버깅 도구

n8n 로그 확인

# 상세 로그 출력으로 n8n 실행
N8N_LOG_LEVEL=debug n8n start

네트워크 요청 모니터링

  1. 브라우저 개발자 도구 열기 (F12)
  2. "Network" 탭에서 API 요청 확인
  3. 실패한 요청의 상세 내용 검토

📊 8. 성능 모니터링

기본 메트릭 추적

실행 성공률 계산

// n8n Function 노드에서 사용할 수 있는 성공률 계산 로직
const totalExecutions = $('Get Executions').itemMatches.length;
const successfulExecutions = $('Get Executions').itemMatches.filter(
  execution => execution.json.status === 'success'
).length;

const successRate = (successfulExecutions / totalExecutions) * 100;

return {
  successRate: Math.round(successRate * 100) / 100,
  totalExecutions,
  successfulExecutions
};

API 응답 시간 모니터링

// 각 API 호출의 응답 시간 측정
const startTime = Date.now();
// ... API 호출
const endTime = Date.now();
const responseTime = endTime - startTime;

console.log(`API Response Time: ${responseTime}ms`);

알림 설정

성공률 90% 미만 시 알림

if (successRate < 90) {
  const alertMessage = {
    text: `🚨 경고: 워크플로우 성공률이 ${successRate}%로 낮습니다!`,
    channel: "#alerts"
  };
  // 슬랙 알림 발송
}
