📝 기본 코딩 팁 프롬프트 (MVP용)

기본 템플릿

개발자를 위한 실용적인 코딩 팁 하나를 3문장으로 작성해주세요.

요구사항:
- 실제로 도움이 되는 구체적인 팁
- 친근하고 유익한 톤
- 마지막에 관련 해시태그 2-3개 포함
- 전체 280자 이내

예시 주제: VSCode 확장프로그램, Git 명령어, 디버깅 기법, 코드 리뷰, 생산성 도구 등

구체적인 주제별 프롬프트

🔧 VSCode 관련

VSCode를 더 효율적으로 사용하는 팁을 하나 알려주세요. 단축키, 확장프로그램, 설정 중 하나를 선택해서 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

🌿 Git 관련

Git을 사용할 때 유용한 명령어나 기법을 하나 소개해주세요. 실제 사용 예시와 함께 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

🐛 디버깅 관련

프로그래밍 중 발생하는 버그를 효과적으로 찾고 해결하는 방법을 하나 알려주세요. 구체적인 예시와 함께 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

📚 코드 리뷰 관련

좋은 코드 리뷰를 위한 팁이나 코드 품질을 높이는 방법을 하나 소개해주세요. 실용적인 조언을 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

⚡ 생산성 도구 관련

개발 생산성을 높이는 도구나 방법을 하나 추천해주세요. 구체적인 사용법과 효과를 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

🎯 향후 확장용 프롬프트 (전체 PRD 구현 시)

🤖 AI 도구 비교

ChatGPT, Claude, GitHub Copilot 등 AI 도구 중 하나를 선택해서 특정 상황에서의 활용법을 비교 분석해주세요. 언제 어떤 도구가 더 유용한지 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

📈 자기계발

개발자의 성장과 자기계발에 도움이 되는 조언을 하나 해주세요. 실천 가능한 구체적인 방법을 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

📚 책 명언

개발자에게 도움이 되는 유명한 책(기술서, 자기계발서, 경영서 등)에서 인상 깊은 구절이나 핵심 내용을 하나 소개해주세요. 책 제목과 함께 그 내용이 개발자에게 어떤 도움이 되는지 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

💰 부자 마인드

개발자가 경제적 자유를 얻거나 올바른 투자 마인드를 기르는 데 도움이 되는 조언을 해주세요. 기술력과 연결지어 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

📊 프롬프트 최적화 가이드

✅ 좋은 결과를 위한 요소

  1. 구체적인 주제 제한: 너무 넓은 주제보다는 구체적인 영역 지정
  2. 문장 수 제한: 3문장으로 제한하여 간결함 유지
  3. 글자 수 제한: 280자로 스레드 플랫폼에 최적화
  4. 해시태그 포함: SEO와 발견성을 위한 필수 요소
  5. 톤앤매너 지정: 친근하고 유익한 톤으로 통일

⚠️ 피해야 할 요소

  1. 너무 추상적인 조언: 실행하기 어려운 막연한 내용
  2. 과도한 기술 용어: 일반 개발자가 이해하기 어려운 전문용어
  3. 부정적인 톤: 비판적이거나 부정적인 내용
  4. 광고성 내용: 특정 제품이나 서비스 홍보
  5. 정치적/종교적 내용: 논란이 될 수 있는 주제

🔄 A/B 테스트용 변형 프롬프트

버전 A: 질문형 시작

"왜 이 코딩 팁을 모르고 있었을까요?" 하고 생각하게 만드는 실용적인 개발 팁을 하나 소개해주세요. 구체적인 예시와 함께 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

버전 B: 감탄사형 시작

"와, 이렇게 하면 되는구나!" 하고 감탄하게 만드는 개발 꿀팁을 하나 알려주세요. 실제 사용 예시와 함께 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

버전 C: 스토리형 시작

많은 개발자들이 놓치고 있는 숨겨진 기능이나 팁을 하나 공유해주세요. 왜 유용한지와 어떻게 사용하는지를 3문장으로 설명하고, 관련 해시태그 2-3개를 포함해주세요. 280자 이내로 작성해주세요.

📝 프롬프트 성능 평가 기준

📊 품질 지표

  1. 길이 적합성: 280자 이내 준수 여부
  2. 해시태그 포함: 2-3개 적절한 해시태그 포함
  3. 실용성: 실제 적용 가능한 구체적인 팁
  4. 가독성: 명확하고 이해하기 쉬운 문장 구조
  5. 참여 유도: 독자의 관심을 끄는 내용

🎯 개선 방향

  • 주간 분석: 가장 좋은 반응을 얻은 콘텐츠의 패턴 분석
  • 프롬프트 업데이트: 분석 결과를 바탕으로 프롬프트 개선
  • 계절성 반영: 연말, 신년, 여름휴가 등 시기별 맞춤 콘텐츠
  • 트렌드 반영: 최신 개발 트렌드나 이슈를 프롬프트에 반영
