02.ToDo-ph1

✅ To Do List - Phase 1: 스레드 자동 업로드 MVP

🎯 핵심 목표

OpenAPI 기반 n8n 워크플로우로 Threads에 콘텐츠 자동 게시 시스템 구축

📋 진행 상황

✅ 완료된 작업

  • PRD 문서 작성 (01.PRD-ph1.md)

🔄 진행 중인 작업

  • n8n 워크플로우 설계 및 구현

⏳ 대기 중인 작업

  • Threads API 인증 설정
  • 워크플로우 테스트 및 검증

🔧 기술 구현 To Do

1. 환경 설정

  • OpenAI API 키 발급 및 설정
  • Threads API 앱 등록 및 토큰 발급
  • Slack Webhook URL 생성
  • n8n 인스턴스 설치 및 설정

2. n8n 워크플로우 개발

  • Cron 트리거 노드 설정 (5회/일)
  • OpenAI 콘텐츠 생성 노드 구현
  • 콘텐츠 검증 코드 노드 개발
  • Threads API HTTP 요청 노드 설정
  • 성공/실패 알림 노드 구현

3. API 연동

  • Threads Graph API 연동 테스트
  • 인증 토큰 자동 갱신 설정
  • API 응답 처리 로직 구현
  • 에러 핸들링 및 재시도 로직

4. 콘텐츠 템플릿

  • 5가지 카테고리별 프롬프트 템플릿 작성
  • 콘텐츠 품질 검증 규칙 정의
  • 해시태그 자동 생성 로직
  • 콘텐츠 다양성 보장 메커니즘

5. 테스트 및 검증

  • 단위 테스트: 각 노드별 기능 검증
  • 통합 테스트: 전체 워크플로우 테스트
  • 성능 테스트: 응답 시간 및 안정성 확인
  • 실제 게시 테스트: 샌드박스 환경에서 검증

6. 모니터링 및 운영

  • 로깅 시스템 구축
  • 성공/실패 모니터링 대시보드
  • 알림 시스템 최적화
  • 운영 매뉴얼 작성

📅 일정 계획

1주차: 기본 설정

  • Day 1: API 키 발급 및 환경 설정
  • Day 2: n8n 기본 워크플로우 구조 설계
  • Day 3: OpenAI 연동 및 콘텐츠 생성 테스트
  • Day 4: Threads API 연동 테스트
  • Day 5: 기본 워크플로우 완성

2주차: 고도화

  • Day 6: 콘텐츠 검증 로직 강화
  • Day 7: 5가지 카테고리별 템플릿 완성
  • Day 8: 에러 핸들링 및 재시도 로직
  • Day 9: 모니터링 및 알림 시스템
  • Day 10: 전체 시스템 테스트 및 배포

🎯 성공 기준

  • 게시 성공률 95% 이상 달성
  • 일일 5회 정확한 스케줄링
  • 콘텐츠 품질 기준 충족 (280자 이내, 해시태그 2-3개)
  • 시스템 안정성 확보 (99% 가동률)

📝 메모

  • MVP는 단일 카테고리로 시작하여 점진적으로 확장
  • 에러 발생 시 즉시 Slack 알림 전송
  • 모든 API 호출은 로그 기록 필수
  • 테스트는 반드시 샌드박스 환경에서 진행
