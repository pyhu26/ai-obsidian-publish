🔐 환경변수 설정 가이드

📋 필요한 API 키 및 계정 목록

1️⃣ OpenAI API 키

  • 사용 목적: AI 콘텐츠 생성
  • 필수 여부: ✅ 필수
  • 예상 비용: 월 $5-10 (MVP 기준)

2️⃣ Meta (Instagram/Threads) API 키

  • 사용 목적: 스레드 게시
  • 필수 여부: ✅ 필수
  • 예상 비용: 무료 (API 사용량 제한 있음)

3️⃣ 슬랙 웹훅 URL

  • 사용 목적: 성공/실패 알림
  • 필수 여부: ⚠️ 권장 (디버깅용)
  • 예상 비용: 무료

🔑 1. OpenAI API 키 발급

1단계: OpenAI 계정 생성

  1. OpenAI Platform 접속
  2. 계정 생성 또는 로그인
  3. 결제 방법 등록 (신용카드 필요)

2단계: API 키 생성

  1. 우측 상단 프로필 → "View API keys" 클릭
  2. "Create new secret key" 버튼 클릭
  3. 키 이름 입력 (예: "threads-automation")
  4. ⚠️ 중요: 생성된 키를 안전한 곳에 복사해두기 (다시 볼 수 없음)

3단계: 사용량 제한 설정

  1. "Settings" → "Limits" 메뉴 이동
  2. Monthly budget limit 설정 (권장: $20)
  3. Usage alerts 설정 (예: $10 도달 시 알림)
예시 API 키 형식:
sk-proj-abcdefghijklmnopqrstuvwxyz1234567890ABCDEFGHIJKLMNOPQR

📱 2. Meta (Threads) API 설정

⚠️ 주의사항

현재 Threads API는 베타 테스트 단계로 제한적으로 제공됩니다.
대안으로 Instagram API를 통한 Cross-posting을 검토할 수 있습니다.

1단계: Meta Business 계정 생성

  1. Meta Business Suite 접속
  2. 비즈니스 계정 생성 또는 기존 계정 사용
  3. Instagram 계정을 비즈니스 계정으로 전환

2단계: Facebook Developer 앱 생성

  1. Facebook Developers 접속
  2. "내 앱" → "앱 만들기" 클릭
  3. 앱 유형: "기타" 선택
  4. 앱 이름 입력 (예: "스레드 자동화")

3단계: 제품 추가 및 권한 설정

  1. 앱 대시보드에서 "제품 추가" 클릭
  2. "Instagram Basic Display" 또는 "Threads API" 선택
  3. 필요한 권한 요청:
    • threads_basic
    • threads_content_publish

4단계: 액세스 토큰 생성

  1. "도구" → "그래프 API 탐색기" 이동
  2. 사용자 액세스 토큰 생성
  3. 필요한 권한 선택
  4. 토큰을 안전한 곳에 저장
예시 액세스 토큰 형식:
IGQVJYeUxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

🚨 대안: 테스트용 목업 API

실제 Threads API 접근이 어려운 경우, 테스트용으로 목업 응답을 사용할 수 있습니다:

{
  "id": "mock_post_id_12345",
  "status": "success",
  "message": "Post created successfully"
}

📢 3. 슬랙 웹훅 설정

1단계: 슬랙 워크스페이스 준비

  1. 기존 워크스페이스 사용 또는 새로 생성
  2. 알림받을 채널 생성 (예: #threads-automation)

2단계: Incoming Webhook 앱 추가

  1. 슬랙에서 "앱" → "앱 디렉터리 찾아보기" 클릭
  2. "Incoming WebHooks" 검색하여 설치
  3. "슬랙에 추가" 버튼 클릭

3단계: 웹훅 URL 생성

  1. 알림받을 채널 선택 (예: #threads-automation)
  2. "Incoming WebHook 통합 앱 추가" 클릭
  3. 생성된 Webhook URL 복사
예시 웹훅 URL 형식:
https://hooks.slack.com/services/T00000000/B00000000/XXXXXXXXXXXXXXXXXXXXXXXX

4단계: 테스트 메시지 발송

curl -X POST -H 'Content-type: application/json' \
--data '{"text":"🤖 n8n 워크플로우 테스트 메시지"}' \
YOUR_WEBHOOK_URL

⚙️ 4. n8n 환경변수 설정

방법 1: n8n 웹 인터페이스에서 설정

1단계: 크리덴셜 생성

  1. n8n 웹 인터페이스 접속
  2. "Credentials" 메뉴 클릭
  3. 각 API별 크리덴셜 생성:

OpenAI 크리덴셜:

  • 타입: OpenAI API
  • 이름: "OpenAI API"
  • API Key: sk-proj-your-openai-api-key

HTTP Header Auth 크리덴셜 (Threads용):

  • 타입: HTTP Header Auth
  • 이름: "Threads API"
  • Header Name: Authorization
  • Header Value: Bearer YOUR_THREADS_TOKEN

방법 2: 환경변수 파일(.env) 사용

n8n 서버 실행 시 환경변수를 설정합니다:

# .env 파일 예시
OPENAI_API_KEY=sk-proj-your-openai-api-key-here
THREADS_ACCESS_TOKEN=IGQVJYeU-your-threads-token-here
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T00000000/B00000000/XXXXXXXXXXXXXXXXXXXXXXXX

# n8n 관련 설정
N8N_BASIC_AUTH_ACTIVE=true
N8N_BASIC_AUTH_USER=admin
N8N_BASIC_AUTH_PASSWORD=your-secure-password

# 보안 설정 (선택사항)
N8N_ENCRYPTION_KEY=your-32-character-encryption-key

방법 3: Docker 환경변수 설정

docker run -d \
  --name n8n \
  -p 5678:5678 \
  -e OPENAI_API_KEY=sk-proj-your-openai-api-key \
  -e THREADS_ACCESS_TOKEN=IGQVJYeU-your-threads-token \
  -e SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T00/B00/XXX \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

🔒 5. 보안 고려사항

✅ 권장 보안 조치

  1. API 키 암호화: n8n의 내장 암호화 기능 사용
  2. 정기적 순환: 30-90일마다 API 키 갱신
  3. 최소 권한 원칙: 필요한 권한만 부여
  4. IP 제한: 가능한 경우 API 접근 IP 제한 설정
  5. 모니터링: API 사용량 정기 모니터링

⚠️ 피해야 할 것들

  1. 코드에 직접 삽입: API 키를 코드에 하드코딩
  2. 공개 저장소: GitHub 등에 API 키 업로드
  3. 로그 노출: 로그 파일에 API 키 기록
  4. 브라우저 노출: 클라이언트 사이드에서 API 키 사용

🛡️ API 키 유출 시 대응방안

  1. 즉시 비활성화: 해당 API 키 즉시 삭제
  2. 새 키 생성: 새로운 API 키 발급
  3. 사용량 모니터링: 비정상적인 사용량 패턴 확인
  4. 계정 보안 강화: 2FA 활성화, 비밀번호 변경

📊 6. 비용 모니터링 및 최적화

💰 예상 월간 비용 (MVP 기준)

서비스 사용량 예상 비용 설명
OpenAI API ~900 요청/월 $3-8 gpt-4o-mini 모델 사용
Threads API ~30 게시/월 무료 현재 무료 제공
슬랙 웹훅 ~60 알림/월 무료 무제한 무료
총계 $3-8/월

📈 비용 최적화 팁

  1. 모델 선택: GPT-4o-mini 사용 (GPT-4 대비 20배 저렴)
  2. 토큰 제한: 응답 길이를 150 토큰으로 제한
  3. 캐싱: 유사한 요청에 대한 응답 캐싱 고려
  4. 배치 처리: 가능한 경우 배치 API 사용

🔔 사용량 알림 설정

// n8n에서 비용 추적 노드 예시
if (monthlyUsage > budgetLimit * 0.8) {
  sendSlackAlert(`⚠️ API 사용량이 예산의 80%를 초과했습니다. 현재: $${monthlyUsage}`);
}

🧪 기본 테스트 완료

  • OpenAI API 호출 테스트
  • Threads API 호출 테스트 (또는 목업 응답 확인)
  • 슬랙 알림 발송 테스트

🔒 보안 설정 완료

  • API 키 암호화 설정
  • 사용량 제한 및 알림 설정
  • 기본 인증 또는 OAuth 설정

🆘 문제해결 가이드

자주 발생하는 오류들

OpenAI API 오류

Error: Incorrect API key provided

해결방법: API 키가 올바른지 확인, sk-proj로 시작하는지 확인

Threads API 오류

Error: Invalid access token

해결방법: Instagram 계정이 비즈니스 계정으로 전환되었는지 확인

슬랙 웹훅 오류

Error: channel_not_found

해결방법: 채널명 확인 및 봇 권한 확인

🔍 디버깅 도구

  1. n8n 실행 로그: 콘솔에서 상세 로그 확인
  2. API 테스트 도구: Postman, curl 등으로 개별 API 테스트
  3. 네트워크 모니터링: 브라우저 개발자 도구로 네트워크 요청 확인
