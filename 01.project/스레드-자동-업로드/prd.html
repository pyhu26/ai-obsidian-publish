🎯 1. 프로젝트 개요

1.1 프로젝트 목적

n8n 워크플로우 자동화 도구를 활용하여 하루 5회 스레드(Threads) 플랫폼에 다양한 주제의 고품질 콘텐츠를 자동으로 게시하는 시스템을 구축합니다.

1.2 핵심 가치 제안

  • ⏰ 완전 자동화: 수동 개입 없이 정해진 시간에 콘텐츠 게시
  • 🎨 다양성: 5가지 서로 다른 주제 카테고리로 구성
  • 🤖 AI 기반: 인공지능을 활용한 고품질 콘텐츠 생성
  • 📊 데이터 기반: 성과 분석을 통한 지속적 개선

1.3 성공 지표 (KPI)

  • 게시 성공률: 95% 이상
  • 일일 게시 횟수: 정확히 5회
  • 콘텐츠 품질: 평균 3문장, 해시태그 2-3개 포함
  • 사용자 참여: 좋아요, 댓글, 공유 수 증가

// Function 노드 검증 로직
const content = $json.choices[0].message.content;
const conditions = {
  length: content.length <= 280,
  sentences: content.split('.').length <= 4,
  hashtags: (content.match(/#\w+/g) || []).length >= 2,
  korean: /[ㄱ-ㅎ|ㅏ-ㅣ|가-힣]/.test(content)
};

return {
  valid: Object.values(conditions).every(Boolean),
  content: content,
  checks: conditions
};
