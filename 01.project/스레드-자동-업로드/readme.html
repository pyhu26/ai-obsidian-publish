🚀 n8n 스레드 자동 업로드 MVP

PRD 기반으로 제작된 테스트 가능한 n8n 워크플로우 MVP입니다.

🎯 MVP 개요

하루 1회 (오전 9시) 스레드에 AI 생성 코딩 팁을 자동으로 게시하는 최소 기능 제품입니다.

핵심 기능

  • 🤖 AI 콘텐츠 생성: OpenAI를 활용한 고품질 코딩 팁 생성
  • ⏰ 자동 스케줄링: 매일 오전 9시 자동 실행
  • 📱 스레드 자동 게시: Threads API를 통한 자동 게시
  • 📊 실시간 알림: 성공/실패 상태를 슬랙으로 즉시 알림
  • ✅ 품질 검증: 콘텐츠 길이, 해시태그, 언어 등 자동 검증

스레드 자동 업로드/

├── PRD.md                         # 전체 프로젝트 요구사항 정의서

├── prompt-templates.md            # AI 프롬프트 템플릿 모음

└── 설치-및-테스트-가이드.md        # 단계별 설치 및 테스트 방법

🚀 빠른 시작

1. 사전 준비

  • OpenAI API 키 발급
  • Meta/Instagram 비즈니스 계정 및 API 키
  • 슬랙 웹훅 URL (선택사항)

2. n8n 설치 및 실행

npm install n8n -g
n8n start

3. 워크플로우 가져오기

  1. http://localhost:5678 접속
  2. "Import" → "From File" → threads-mvp-workflow.json 업로드
  3. 각 노드에 크리덴셜 연결
  4. "Save" 및 "Activate"

4. 테스트 실행

  • 수동 실행으로 전체 플로우 테스트
  • 각 단계별 개별 테스트
  • 자동 스케줄링 설정 및 검증

📚 상세 가이드

가이드 설명 추천 순서

🛠️ 워크플로우 구조

✅ 테스트 체크리스트

기본 연결 테스트

  • OpenAI API 응답 테스트
  • Threads API 게시 테스트
  • 슬랙 알림 발송 테스트

워크플로우 테스트

  • 전체 워크플로우 수동 실행
  • 콘텐츠 품질 검증 로직 테스트
  • 에러 처리 및 알림 테스트

자동화 테스트

  • 크론 스케줄러 정상 작동 확인
  • 3일 연속 자동 실행 성공
  • 90% 이상 성공률 달성

📊 성공 기준 (1주 MVP 테스트)

지표 목표 측정 방법
게시 성공률 90% 이상 n8n 실행 이력 확인
콘텐츠 품질 280자 이내, 해시태그 2-3개 자동 검증 로직
시스템 안정성 7일 중 5일 이상 성공 슬랙 알림 모니터링
응답 시간 평균 10초 이내 노드별 실행 시간 측정

🔄 향후 확장 계획

Phase 2: 다중 카테고리 (PRD의 20%)

  • 5가지 콘텐츠 카테고리 추가
  • 하루 5회 게시로 확장
  • 시간대별 최적화

Phase 3: 고도화 (PRD의 50%)

  • 성과 분석 대시보드
  • A/B 테스트 시스템
  • 콘텐츠 중복 방지

Phase 4: 완전체 (PRD의 100%)

  • 멀티 플랫폼 지원
  • 머신러닝 기반 최적화
  • 완전 자율 운영

⚠️ 알려진 제한사항

현재 MVP 제약

  • 단일 카테고리: 코딩 팁만 지원 (향후 5가지로 확장 예정)
  • 하루 1회: 오전 9시만 실행 (향후 5회로 확장 예정)
  • 기본 검증: 간단한 길이/해시태그 검증만 지원
  • Threads API 제한: 베타 상태로 불안정할 수 있음

비용 예상

  • OpenAI API: 월 $3-8 (gpt-4o-mini 사용)
  • Threads API: 무료 (현재 베타)
  • 인프라: $0-5 (로컬 실행 시 무료)

🆘 문제해결

자주 발생하는 문제들

문제 원인 해결방법
OpenAI API 401 오류 잘못된 API 키 키 재발급 및 재설정
Threads API 오류 토큰 만료 Instagram 비즈니스 계정 재인증
슬랙 알림 실패 잘못된 웹훅 URL 웹훅 URL 재확인
콘텐츠 품질 실패 프롬프트 문제 프롬프트 템플릿 재검토
