CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

저장소 개요

이 저장소는 AI 및 분석 도구에 중점을 둔 Obsidian 보관함으로, 특히 ccusage(Claude Code 토큰 사용량 분석기)에 대한 문서를 포함하고 있습니다. 보관함은 한국어로 구성되어 있으며 AI 관련 도구와 워크플로우의 지식 베이스 역할을 합니다.

보관함 구조

  • 콘텐츠: AI 도구 및 분석에 중점을 둔 한국어 마크다운 파일들
  • 설정: 워크스페이스 및 플러그인 구성이 포함된 .obsidian/ 디렉토리가 있는 표준 Obsidian 보관함
  • 언어: 주요 콘텐츠는 한국어

Obsidian 보관함 작업 가이드

파일 관리

  • 모든 콘텐츠 파일에는 .md 확장자 사용
  • 내부 링크에는 Obsidian의 이중 대괄호 [[링크]] 문법 유지
  • YAML 메타데이터가 포함된 기존 frontmatter 구조 준수 (title, created, updated, tags 등)

콘텐츠 작성 규칙

  • 파일은 주로 한국어 사용
  • 문서는 명확한 제목이 있는 구조화된 형식을 따름
  • 분류를 위해 태그를 광범위하게 사용 (예: ccusage, claude-code, token-analysis)
  • frontmatter를 통한 상태 추적 (status: active)

사용 중인 Obsidian 기능

  • 노트 연결 시각화를 위한 그래프 뷰
  • 알파벳 순 정렬이 있는 파일 탐색기
  • 검색 기능
  • 백링크 및 나가는 링크 추적
  • 빈도 정렬이 있는 태그 관리
  • 문서 구조를 위한 개요 뷰

워크스페이스 구성

  • 그래프 뷰가 활성화된 주요 뷰
  • 왼쪽 사이드바: 파일 탐색기, 검색, 북마크
  • 오른쪽 사이드바: 백링크, 나가는 링크, 태그, 개요 (기본적으로 접혀 있음)
  • 빠른 액세스 도구가 있는 표준 Obsidian 리본

콘텐츠 가이드라인

콘텐츠를 생성하거나 편집할 때:

  • 확립된 한국어 문서 스타일을 따름
  • 적절한 메타데이터 필드가 있는 frontmatter 사용
  • 일관된 태그 분류 체계 유지
  • 명확한 제목과 섹션으로 콘텐츠 구조화
  • [[]] 문법을 사용하여 관련 상호 참조 포함

특별 고려사항

  • 이 보관함은 코드보다는 문서에 중점을 둔 것으로 보임
  • 빌드 명령어, 테스팅 프레임워크, 또는 개발 툴체인은 없음
  • 주요 워크플로우는 Obsidian을 통한 콘텐츠 생성 및 지식 관리
