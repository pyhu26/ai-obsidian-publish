ccusage - Claude Code Token Usage Analyzer

ccusage - Claude Code 토큰 사용량 분석 도구

Claude Code의 토큰 사용량과 비용을 로컬 JSONL 파일에서 분석하는 CLI 도구입니다.

주요 특징

  • 📊 일별/월별/세션별 사용량 리포트
  • 💰 실시간 비용 추적 및 모니터링
  • 🎯 Claude 모델별 토큰 및 비용 분석
  • 📅 날짜, 프로젝트, 시간대별 필터링
  • 📱 컴팩트 및 JSON 출력 옵션
  • 🌐 다중 로케일 및 시간대 지원
  • ⚡ 초소형 번들 사이즈

설치 방법

권장 방법 (즉시 실행)

bunx ccusage        # 가장 빠른 방법
npx ccusage@latest  # 대안

전역 설치

npm install -g ccusage

주요 명령어

기본 리포트

  • ccusage - 기본 일별 리포트
  • ccusage daily - 상세한 일별 토큰 사용량
  • ccusage monthly - 월별 집계 리포트
  • ccusage session - 대화 세션별 사용량
  • ccusage blocks - 5시간 빌링 윈도우 추적

실시간 모니터링

  • ccusage blocks --live - 실시간 사용량 대시보드

유용한 플래그 및 옵션

날짜 필터링

  • --since [날짜] - 시작 날짜 지정
  • --until [날짜] - 종료 날짜 지정

출력 형식

  • --json - JSON 형태로 데이터 내보내기
  • --compact - 압축된 표시 모드
  • --breakdown - 모델별 비용 분석

그룹화 옵션

  • --instances - 프로젝트별 그룹화

사용 예시

기본 사용량 확인

ccusage daily

특정 기간 분석

ccusage monthly --since 2025-01-01 --until 2025-01-31

실시간 모니터링

ccusage blocks --live

JSON으로 데이터 내보내기

ccusage session --json --breakdown

효율적인 사용 팁

1. 정기적인 모니터링

  • blocks --live로 실시간 사용량 추적
  • 일별 리포트로 패턴 파악

2. 비용 최적화

  • --breakdown 플래그로 모델별 비용 분석
  • 월별 리포트로 예산 관리

3. 프로젝트 관리

  • --instances로 프로젝트별 사용량 분리
  • 세션별 분석으로 효율성 측정

4. 데이터 활용

  • --json 출력으로 추가 분석
  • 특정 기간 필터링으로 트렌드 파악

주요 장점

🚀 성능

  • 초소형 번들 사이즈로 빠른 실행
  • 오프라인 가격 데이터 지원

🎨 사용성

  • 컬러풀하고 반응형 출력
  • 직관적인 CLI 인터페이스

📊 분석 기능

  • 다양한 리포트 형식 제공
  • 세분화된 사용량 추적
