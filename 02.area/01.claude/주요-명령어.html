Claude Code 주요 명령어 가이드

Claude Code 주요 명령어 가이드

Claude Code CLI의 핵심 명령어들과 실제 사용 예제를 정리한 참고 문서입니다.

기본 명령어

1. 초기화 및 설정

/init - 프로젝트 초기화

# 현재 디렉토리를 Claude Code 프로젝트로 초기화
claude /init
  • 코드베이스 분석 후 CLAUDE.md 파일 생성
  • 프로젝트 구조와 개발 가이드라인 자동 생성

/help - 도움말

# Claude Code 사용법 확인
claude /help

2. 파일 및 디렉토리 작업

/read - 파일 읽기

# 특정 파일 내용 확인
claude /read src/main.js

# 여러 파일 동시 읽기
claude /read src/main.js src/utils.js

/write - 파일 작성

# 새 파일 생성
claude /write src/new-file.js "console.log('Hello World');"

/edit - 파일 수정

# 기존 파일 수정
claude /edit src/main.js

3. 검색 및 분석

/search - 코드 검색

# 패턴 검색
claude /search "function.*authenticate"

# 특정 파일 타입에서 검색
claude /search "useState" --type js,jsx,ts,tsx

/find - 파일 찾기

# 파일명으로 검색
claude /find "*.component.js"

# 디렉토리 내 특정 패턴 파일 찾기
claude /find "test" --pattern "*.spec.js"

4. Git 작업

커밋 관련

# 변경사항 커밋
claude "commit these changes with a descriptive message"

# 스테이징과 커밋 함께
claude "add all files and commit with message: feat: add new feature"

브랜치 작업

# 새 브랜치 생성 및 전환
claude "create new branch feature/user-auth"

# Pull Request 생성
claude "create PR for current branch"

5. 개발 도구 통합

빌드 및 테스트

# 프로젝트 빌드
claude "build the project"

# 테스트 실행
claude "run tests"

# 린팅 및 포맷팅
claude "lint and format the code"

패키지 관리

# 의존성 설치
claude "install express as dependency"

# 개발 의존성 설치
claude "install jest as dev dependency"

고급 사용법

1. 멀티 태스크 실행

# 여러 작업을 순차적으로 실행
claude "run tests, fix any failures, then build the project"

# 병렬 실행 지시
claude "run lint and tests in parallel"

2. 조건부 작업

# 조건부 실행
claude "if tests pass, then deploy to staging"

# 에러 핸들링
claude "build project, if it fails show me the errors"

3. 코드 분석 및 리팩토링

# 코드 품질 분석
claude "analyze code quality in src/ directory"

# 리팩토링 제안
claude "suggest improvements for performance in utils.js"

# 보안 검사
claude "check for security vulnerabilities in dependencies"

실용적인 사용 예제

프로젝트 셋업

# 새 React 프로젝트 초기화
claude "create new React project with TypeScript and Tailwind"

# Express API 서버 셋업
claude "setup Express server with middleware for CORS and logging"

디버깅

# 에러 분석
claude "analyze this error and suggest fixes: [에러 메시지]"

# 성능 문제 해결
claude "why is my app loading slowly? check bundle size and optimize"

코드 리뷰

# 코드 리뷰 요청
claude "review my code changes and suggest improvements"

# 베스트 프랙티스 확인
claude "check if this code follows React best practices"

문서화

# API 문서 생성
claude "generate API documentation for my Express routes"

# README 업데이트
claude "update README with installation and usage instructions"

효율적인 사용 팁

1. 명확한 지시사항

  • 구체적이고 명확한 요청
  • 예상 결과 명시
  • 제약사항 포함

2. 컨텍스트 제공

# 좋은 예
claude "refactor this authentication function to use async/await instead of callbacks, maintaining the same API"

# 개선이 필요한 예
claude "fix this code"

3. 단계별 작업

# 복잡한 작업을 단계별로 분할
claude "first analyze the current database schema, then suggest migration steps for the new requirements"

4. 검증 요청

# 변경사항 검증 요청
claude "implement this feature and run tests to verify it works correctly"

주의사항

보안

  • 민감한 정보(API 키, 패스워드) 포함 금지
  • 프로덕션 데이터 직접 조작 시 주의

성능

  • 대용량 파일 처리 시 부분적으로 나누어 요청
  • 복잡한 작업은 단계별로 분할

협업

  • 커밋 메시지는 팀 컨벤션 준수
  • 코드 변경 전 백업 또는 브랜치 생성
