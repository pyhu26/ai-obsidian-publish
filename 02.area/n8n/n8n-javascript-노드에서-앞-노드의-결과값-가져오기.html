n8n JavaScript 노드에서 앞 노드의 결과값 가져오기

주요 방법

1. 현재 아이템 접근 (기본)

// 현재 아이템의 데이터
const currentItem = $input.item.json;
const value = currentItem.fieldName;

// 또는 직접 접근
const value = $input.item.json.fieldName;

2. 모든 아이템 접근

// Code 노드에서 items 배열 사용
const allItems = items;
const firstItem = items[0].json;
const secondItem = items[1].json;

// 모든 아이템 순회
items.forEach((item, index) => {
  console.log(item.json);
});

3. 특정 노드의 결과 접근

// 특정 노드의 첫 번째 아이템
const nodeData = $node["노드이름"].json;

// 특정 노드의 특정 아이템
const specificItem = $node["노드이름"].item.json;

// 특정 노드의 파라미터
const param = $node["노드이름"].parameter;

4. 이전 노드 접근 (Expression)

// Expression에서 사용
={{ $json.fieldName }}

// 특정 노드 지정
={{ $node["파라미터 설정"].json.unit }}

// 첫 번째 아이템
={{ $input.first().json.fieldName }}

// 마지막 아이템
={{ $input.last().json.fieldName }}

실제 예시

예시 1: 이전 노드의 데이터 가져오기

// Code 노드
const previousData = items[0].json;
const marketName = previousData.market;
const price = previousData.price;

return items.map(item => ({
  json: {
    market: item.json.market,
    processedPrice: item.json.price * 1.1
  }
}));

예시 2: 여러 노드의 데이터 조합

// "전체 마켓 조회" 노드의 결과
const markets = $node["전체 마켓 조회"].json;

// "파라미터 설정" 노드의 값
const unit = $node["파라미터 설정"].json.unit;

// 현재 아이템
const currentCandle = items[0].json;

return [{
  json: {
    marketInfo: markets,
    unit: unit,
    candleData: currentCandle
  }
}];

예시 3: HTTP Request URL에서 사용

// HTTP Request 노드의 URL 필드 (Expression 모드)
=https://api.upbit.com/v1/candles/minutes/{{ $node['파라미터 설정'].json.unit }}?market={{ $json.market }}&count={{ $node['파라미터 설정'].json.count }}

주요 변수 정리

변수 설명 사용 위치
$json 현재 아이템의 JSON 데이터 Expression
$input 입력 아이템 전체 Expression, Code
items 모든 입력 아이템 배열 Code 노드
$node["노드이름"] 특정 노드의 데이터 Expression, Code
$input.first() 첫 번째 아이템 Expression
$input.last() 마지막 아이템 Expression
$input.item 현재 아이템 Expression

Code 노드 반환 형식

// 단일 아이템 반환
return [{
  json: {
    field1: value1,
    field2: value2
  }
}];

// 여러 아이템 반환
return items.map(item => ({
  json: {
    original: item.json,
    processed: processData(item.json)
  }
}));

// 조건부 필터링
return items
  .filter(item => item.json.price > 1000)
  .map(item => ({
    json: item.json
  }));

디버깅 팁

Console 출력

// 데이터 구조 확인
console.log('Current item:', JSON.stringify($input.item.json, null, 2));
console.log('All items count:', items.length);
console.log('First item:', items[0].json);

에러 처리

try {
  const data = $node["이전노드"].json;
  // 데이터 처리
} catch (error) {
  console.error('Error accessing node data:', error.message);
  return [{
    json: {
      error: error.message
    }
  }];
}

주의사항

  1. 노드 이름 정확성: $node["노드이름"]에서 노드 이름은 정확히 일치해야 합니다 (대소문자, 공백 포함)
  2. 데이터 존재 여부: 노드가 실행되지 않았거나 데이터가 없으면 에러 발생
  3. 배열 인덱스: items[0]는 첫 번째 아이템, 배열이 비어있으면 undefined
  4. Expression vs Code: Expression은 ={{ }}, Code 노드는 순수 JavaScript

실전 활용 패턴

패턴 1: 파라미터와 API 응답 결합

const params = $node["파라미터 설정"].json;
const apiResponse = items[0].json;

return [{
  json: {
    queryParams: params,
    result: apiResponse,
    processedAt: new Date().toISOString()
  }
}];

패턴 2: 여러 아이템 집계

const total = items.reduce((sum, item) => {
  return sum + item.json.price;
}, 0);

const average = total / items.length;

return [{
  json: {
    totalItems: items.length,
    totalPrice: total,
    averagePrice: average,
    items: items.map(i => i.json)
  }
}];

패턴 3: 조건부 분기

const threshold = $node["설정"].json.threshold;

const filtered = items.filter(item => {
  return item.json.value > threshold;
});

return filtered.map(item => ({
  json: {
    ...item.json,
    passedFilter: true
  }
}));
