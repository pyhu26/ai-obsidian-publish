ChatGPT API 사용량 제한하기

ChatGPT API 사용량 제한하기

1. 개요

OpenAI API를 사용하다 보면 예상치 못한 비용이 발생할 수 있습니다. 이를 방지하기 위해 OpenAI는 다양한 사용량 제한 및 예산 관리 기능을 제공합니다.

API 사용량 제한이 필요한 이유

  • 예상치 못한 과금 방지
  • 프로젝트별 비용 관리
  • 개발/테스트 환경에서의 비용 통제
  • 조직 전체의 API 사용량 모니터링

OpenAI의 사용량 관리 기능

  • Usage 모니터링: 실시간 사용량 추적
  • Budget 설정: 월별 예산 한도 설정
  • Rate Limits: API 호출 속도 제한
  • Usage Alerts: 사용량 알림 설정

2. 사용량 확인하기

Usage 페이지 접근 방법

  1. OpenAI Platform 접속
  2. Settings > Organization > Usage 메뉴 선택
  3. 또는 직접 URL 접속: https://platform.openai.com/settings/organization/usage

주요 지표 확인

Total Spend (총 사용 금액)

  • 선택한 기간 동안의 총 사용 금액
  • 일별 사용 금액 그래프로 시각화
  • "Group by" 옵션으로 데이터 그룹화 가능

Total tokens (총 토큰 수)

  • 사용한 총 토큰 수 (입력 + 출력)
  • 토큰 사용량 추이 그래프
  • API 효율성 분석에 활용

Total requests (총 요청 수)

  • API 호출 총 횟수
  • 요청 패턴 분석 가능

API 기능별 사용량 확인

Usage 페이지에서는 다음과 같은 API 기능별로 사용량을 확인할 수 있습니다:

  • Chat Completions: 대화형 API 사용량
  • Images: 이미지 생성 사용량
  • Web Searches: 웹 검색 기능 사용량
  • File Searches: 파일 검색 사용량
  • Embeddings: 임베딩 생성 사용량
  • Audio Speeches: 음성 합성 사용량
  • Audio Transcriptions: 음성 인식 사용량
  • Vector Stores: 벡터 스토어 사용량
  • Code Interpreter Sessions: 코드 인터프리터 사용량
  • Moderation: 콘텐츠 검열 사용량

각 기능별로 요청 수, 토큰 수, 이미지 수 등의 세부 지표를 확인할 수 있습니다.

사용 기간 선택 및 데이터 내보내기

  • 날짜 선택: 기본적으로 최근 2주간 데이터 표시
  • 프로젝트 필터: "All projects" 드롭다운으로 특정 프로젝트만 조회
  • Export 기능: CSV 형식으로 사용량 데이터 다운로드

3. 예산(Budget) 설정하기

Organization Budget 설정 방법

  1. Settings > Organization > Limits 메뉴 선택
  2. "Organization budget" 섹션 확인
  3. Edit budget 버튼 클릭
  4. 월별 예산 금액 입력 (예: $20.00)
  5. 저장

월별 예산 한도 설정

  • 예산은 매월 1일에 자동으로 리셋됩니다
  • 현재 사용량과 남은 예산을 한눈에 확인 가능
  • 예: $0.09 / $20.00 (현재 사용량 / 총 예산)
  • "Resets in X days" 표시로 리셋까지 남은 일수 확인

예산 알림(Alert) 추가하기

Add alert 버튼을 클릭하여 사용량 알림을 설정할 수 있습니다:

80% 사용량 알림

  • 예산의 80%를 사용했을 때 이메일 알림 발송
  • 비용 초과 전 사전 경고

100% 사용량 알림

  • 예산을 모두 사용했을 때 이메일 알림 발송
  • 추가 비용 발생 전 즉각 대응 가능

알림은 조직의 관리자 및 지정된 이메일 주소로 전송됩니다.

4. 사용량 제한(Limits) 이해하기

Rate Limits (속도 제한)

API 사용량은 다음과 같은 속도 제한이 적용됩니다:

TPM (Tokens Per Minute)

  • 분당 처리 가능한 최대 토큰 수
  • 모델별로 다른 제한 적용
  • 예: gpt-4o는 30,000 TPM

RPM/RPD (Requests Per Minute/Day)

  • RPM: 분당 최대 요청 수
  • RPD: 일일 최대 요청 수
  • 대부분의 모델: 500 RPM

모델별 Rate Limits 예시

모델 Token Limits Request Limits Batch Queue Limits
gpt-5 500,000 TPM 500 RPM 1,500,000 TPD
gpt-5-mini 500,000 TPM 500 RPM 5,000,000 TPD
gpt-4.1 30,000 TPM 500 RPM 900,000 TPD
o4-mini 200,000 TPM 500 RPM 2,000,000 TPD

Note: "Show all models" 버튼을 클릭하면 모든 모델의 제한 사항을 확인할 수 있습니다.

자세한 내용은 OpenAI Rate Limits 가이드를 참조하세요.

Usage Limit (월 최대 사용량)

  • OpenAI가 조직에 허용하는 월별 최대 사용 금액
  • Usage Tier에 따라 자동으로 조정
  • 예: 기본 제한은 $120.00/월

Usage Tier 시스템

OpenAI는 사용량에 따라 자동으로 티어를 업그레이드하는 시스템을 운영합니다. 티어가 올라갈수록 더 높은 Rate Limits와 Usage Limits가 적용됩니다.

5. 사용량 티어(Usage Tier) 업그레이드

현재 티어 확인 방법

Limits 페이지 상단에서 현재 Usage tier를 확인할 수 있습니다.

  • Limits 페이지 접속
  • 페이지 상단 "Usage tier X" 표시 확인
  • "Increasing your limits" 섹션에서 상세 정보 확인

상위 티어 승급 조건

Usage Tier 1 → Usage Tier 2 승급 조건:

  1. 최소 사용 금액: 계정 생성 이후 최소 $50 사용
  2. 최소 경과 시간: 첫 결제 성공 후 최소 7일 경과

두 조건을 모두 충족하면 자동으로 다음 티어로 업그레이드됩니다.

티어별 제한 차이

  • Tier 1: 기본 제한 (월 $120 한도)
  • Tier 2: 증가된 Rate Limits 및 Usage Limits
  • Tier 3+: 더욱 높은 제한 (대규모 프로덕션용)

각 티어별 상세 제한 사항은 Usage Tiers 문서에서 확인할 수 있습니다.

승급 진행 상황 확인:

  • View payment history: 결제 이력 확인
  • Buy credits: 크레딧 구매로 사용량 증가

6. 권장 사항

비용 관리를 위한 팁

  1. 개발 환경 분리

    • 개발/테스트용 프로젝트와 프로덕션 프로젝트를 분리
    • 각 프로젝트별로 별도의 API 키 사용

  2. 적절한 예산 설정

    • 초기에는 낮은 예산으로 시작 ($5-20)
    • 사용 패턴 파악 후 점진적으로 증가

  3. 모델 선택 최적화

    • 간단한 작업에는 저렴한 모델 사용 (gpt-4o-mini)
    • 복잡한 작업에만 고성능 모델 사용 (gpt-4, o3)

  4. 토큰 사용량 최적화

    • 불필요한 context 최소화
    • max_tokens 파라미터로 응답 길이 제한
    • 시스템 프롬프트 간결하게 작성

  5. 정기적인 모니터링

    • 주간/월간 사용량 리포트 확인
    • 비정상적인 사용 패턴 조기 발견

알림 설정 권장사항

  1. 80% 알림은 필수

    • 예산 초과 전에 대응할 수 있는 여유 확보
    • 필요시 예산 조정 또는 사용량 제한

  2. 100% 알림 설정

    • 예산 초과 시점 즉시 인지
    • 추가 비용 발생 방지

  3. 여러 담당자에게 알림 전송

    • 조직 관리자뿐만 아니라 개발 팀장에게도 알림
    • 빠른 대응을 위한 다중 알림 체계 구축

  4. Slack/Discord 연동 고려

    • Webhook을 활용한 실시간 알림
    • 팀 전체가 사용량 인지
